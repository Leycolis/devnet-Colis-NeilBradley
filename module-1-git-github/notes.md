## Key vocabulary (in your own words)

- repository: A public or private project that you use
- commit: this save your current files and changes to be ready for a push
- branch: branch is a copy of your main repo but anything you do in that branch does not effect the main repo
- push / pull: push updates your or rather uploads your commits to the remote repo. pull download the new commits from the repo and upload it or combine it in your local
- pull request:its just like asking if you want to merge two files
- merge conflict:its senario when git cant combine the two branch automatically
